Avis de confidentialité

Cet avis décrit comment Mkweli traite les informations lorsque vous utilisez nos sites produit et applications mobiles. Dernière mise à jour : juillet 2026.

Qui nous sommes

Mkweli est un studio produit basé à Grand Baie, Maurice. Contact confidentialité et support : support@mkweli.tech.

Sites web

Nos sites marketing (dont mkweli.tech et les sous-domaines produit) sont des pages statiques. Nous n’utilisons pas de traceurs publicitaires par défaut. Si vous nous écrivez, nous utilisons votre adresse uniquement pour répondre à votre demande.

Les hébergeurs ou CDN (par exemple GitHub Pages ou un hôte équivalent) peuvent traiter des journaux techniques standard : adresse IP, agent utilisateur, et heure de la requête, pour la sécurité et la fiabilité.

Produits

Plusieurs produits Mkweli sont conçus pour fonctionner hors-ligne ou avec peu de données :

  • Mkweli AML : les listes de sanctions peuvent être traitées sur l’appareil ; nous n’exigeons pas de compte cloud pour le filtrage de base dans l’APK pilote gratuit.
  • LakazAgri : les annonces d’offre et de demande que vous créez servent à la coordination ; traitez les données pilote comme non sensibles et n’y mettez pas de données personnelles que vous ne partageriez pas avec un acheteur ou un agriculteur.
  • Assimilate Pro : le contenu du guide est local autant que possible ; la progression peut être stockée sur votre appareil.
  • Mkweli Grid : les journaux de terrain restent sur l’appareil sauf si vous configurez votre propre synchro de bord ; à n’utiliser que pour des essais opérationnels autorisés.
  • Village Grid : un jeu civique dans le navigateur sur honesty.mkweli.tech ; les scores et la progression restent sur votre appareil. Aucun compte n’est requis.

Des précisions propres à chaque produit peuvent figurer dans l’appli ou sur son site. En cas de conflit avec cette page pour ce produit, l’avis produit prime pour ce produit.

Ce que nous ne faisons pas

  • Nous ne vendons pas de données personnelles.
  • Nous n’utilisons pas vos demandes de pilote pour des listes publicitaires de tiers.
